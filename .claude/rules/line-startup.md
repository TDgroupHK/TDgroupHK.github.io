## 七、初创客群业务线（2026-08-08 建立，长期方针）

**背景与定位（用户拍板）**：微信私域联系人以初创公司与小微企业为主，公司整体客户结构也以新创和小公司为大头。既有付费产品（38,000 元上市路线图、陪跑、俱乐部会员）全部瞄准中后期企业，初创客群此前无承接产品。自 2026-08-08 起，初创业务线为官网正式产品线，长期维护。

1. **产品阶梯（价格为对外标准报价，改价须同步 `startup-program.html` 可见文案与其 Service schema 的 offers）**：
   - L0 免费自测：`startup-financing-checkup.html`（融资准备度，8 题）、`founder-equity-checkup.html`（股权健康度，7 题）。定位是私域筛选器：不收集数据、本地计算，靠「一键发邮件换一页纸初评」收线索。
   - L1 一对一资本咨询：2,800 元 / 90 分钟。
   - L2 单项标准品：融资条款审阅 6,800 元、股权架构方案 6,800 元，均为 5 个工作日交付书面方案＋一次一对一。
   - L3 初创资本架构落地：68,000 元起，2–4 个月，对应八大业务中的「架构设计」。
   - **抵扣链（核心销售机制，不得删）**：L1 可抵任一 L2；L2 可抵 L3；L3 可抵 38,000 元上市路线图。按实付金额、无有效期。整条链的叙事是「初创服务是既有产品线的第一段」，与 pre-ipo-program.html、club.html 首尾相接。
2. **文库新增第九分类「初创与早期融资」**（`tools/new_article.py` 的 CAT_LABELS 已加，栏目名「初创融资 EARLY STAGE」，置于 library.html 分类之首）。首批五篇：合伙人股权分配、天使轮估值、初创财务规范、境外架构时机、第一次融资清单。此类文章持续补充，选题围绕「股权、条款、架构、规范」四个付费服务对应的痛点写，文章即销售线索入口。
3. **初创线合规边界（比全站规则再收紧一档）**：
   - 一律**不承诺融资结果**，页面与话术统一口径：「不承诺融资结果、不承诺估值、不作任何收益承诺」。
   - 「帮企业对接资金」只能表述为**合规的信息对接**，且必须落在俱乐部机会池既有机制内（编号披露、签保密件一对一、仅面向合格投资者、充分揭示风险、不构成投资建议）。禁止出现任何形似公开募集宣传的表述。
   - 股权收费模式（服务费折让＋少量股权）**只在面谈中谈，不写上官网**；官网只写现金报价。
4. **内部销售物料只入私有仓库（2026-08-10 修订，原规则为「一律不入库」）**：微信话术、报价策略、客户分层 SOP、股权收费模式等内部物料，**一律不得提交进任何公开仓库**——`TDgroupHK.github.io`、`TDgroup`、`TDgroupHK` 三个仓库全部公开，其中 `TDgroupHK.github.io` 更是 GitHub Pages 源，放进去的文件会被 https://tdgroup.hk 直接对外提供。
   **改为一律提交进私有仓库 `TDgroupHK/td-internal`**（2026-08-10 建立，Private，永不转公开）。原规则「不入任何仓库」的约束来自当时没有非公开的存放处，不是内部物料不该版本化；缺了版本控制反而带来两个后果：换 Claude 账号会丢（对话历史绑账号，官方只导出、不能导入还原），换机重装也会丢。
   该私有仓库同时承接**对话存档**（`tools/claude_archive.py` 把 Claude 对话转成 Markdown 入库）与**涉密决策记录**。分流原则：**不涉密的执行规则仍写进本文件**——`CLAUDE.md` 是每次会话的第一入口，规则挪进私有仓库等于失效；只有报价让利口径、股权收费模式、客户个案判断、合作方商务条件这类真正不能公开的才进私有库。
   密钥、访问令牌、账号 ID 一律不入库，私有仓库也不行。客户公司名即使在私有仓库也按最小必要原则，能用编号代替就用编号。
   **对话与内容按数字资产管理，必须定时同步（2026-08-10 用户拍板）**：所有新对话、新内容都要定期备份进 `td-internal`。三条渠道各管一段——本机定时任务（`tools/schedule_backup.py`，每周日 22:00，覆盖本机 Claude Code 会话）、云端代理自觉归档、季度官方数据导出（覆盖网页版与手机端）。
   **⚠️ 云端会话是最易漏的一段，因此定为硬性约定：任何在云端环境（claude.ai/code 等）工作的 AI 代理，做完实质工作、结束回合之前，必须执行 `python tools/backup.py` 把本次会话归档并推送；若环境拉不到 `td-internal`，必须在回复里明说「本次会话未能归档」，不得默默跳过。** 云端容器一回收，该次会话记录即永久消失，本机定时任务扫不到。
   新鲜度自查用 `python tools/backup.py --status`。详见 `td-internal/迁移/定时备份.md`。
   **交接文档必须每次会话登记（2026-08-10 用户拍板）**：`td-internal/交接文档.md` 是接班人（换账号、换成 Codex 等任何 AI）的第一份读物——现状、在办与阻塞、定期任务清单、工作日志。**归档存的是原始记录，交接文档写的是现状与结论，两者不能互相替代**：没人会去读几百篇聊天记录，但所有人都会读交接文档。
   **因此：任何会话做完实质工作后，除 `backup.py` 外还须执行 `python tools/handover.py --log "一句话说清做了什么" --detail "细节" --tags <标签>`，并同步更新「在办与阻塞」一节**（做完的划掉、新卡住的写上）。现状快照由 `backup.py` 自动刷新，但工作日志必须自己写——只有当次会话知道做了什么、为什么。
   跨厂商接管靠 `td-internal/AGENTS.md` 唯一真源 + `tools/gen_agent_entrypoints.py` 生成的八家入口文件（Claude／Codex-AGENTS／Gemini／Qwen／Aider／Cline／Cursor／Windsurf／Copilot），另有 MCP 服务与上下文打包两条通道，详见 `td-internal/迁移/各家AI接入.md`。
5. **维护要求**：新增初创类落地页/工具页时，须同步 sitemap.xml 与 llms.txt「主要页面」段（该段为人工维护，gen_llms.py 不管）；两个自测页的埋点事件名（`startup_checkup_*`、`equity_checkup_*`）已接 GA4 与百度统计，改版时保留，完成率与线索转化率是判断这两页去留的唯一依据。
6. **短视频线分工（2026-08-08 用户拍板，当日二次修订为采集驱动）**：公域获客走抖音/快手/小红书/视频号短视频。链路＝**扣子空间 Agent 在抖音站内采集已验证爆款并生成视频 → 蚁小二 Agent 多平台发布**；**本仓库会话只做内容中枢**——维护 `TDgroupHK/TDgroup` 仓库 `内容供给/` 目录下的采集指令、改写规范（版权与洗稿安全线：选题/结构/公开事实可采，表达必须全部重写）、合规红线、已验证种子选题与事实库（官网 192 篇文章＝唯一数字来源，llms.txt 为清单）。**不要在本会话里做成品视频**（2026-08-08 做过 5 条已废弃归档），也不要原创堆选题——选题以市场已验证信号为准，内容侧负责改写安全与事实准确。种子选题剩 3 条或扣子侧缺事实源文章时补给。
