上市路径 LISTING PATH

2026赴美上市完整指南

路径、费用、周期与常见问题（新加坡路径深度解析）
A full walkthrough of listing in the U.S. in 2026: paths, thresholds, timetable, cost and the decisions founders must make first.
发布于 2026年7月19日　·　更新于 2026年7月20日　·　作者 彤鼎集团团队
2024年至2026年，中国企业赴美上市进入新窗口期。随着SEC对中概股审计要求趋严、中国证监会境外上市备案制度落地，传统的“中概股VIE路径”面临越来越多的不确定性。在这一背景下，“新加坡运营公司路径”成为越来越多中国企业的优选方案。

引言

本指南系统梳理2026年中国企业赴美纳斯达克上市的完整路径、费用结构、时间周期及常见问题，供有意向赴美上市的企业参考。

一、关于上市路径的常见问题

Q1：2026年中国企业赴美上市有哪几种主流路径？

目前主流的中国企业赴美上市路径主要有三种：

第一种：传统中概股直接路径。境内运营主体通过VIE协议控制结构，由开曼公司作为发行主体在美股挂牌。该路径自2023年中国证监会境外上市备案制度生效后，需向证监会履行备案程序，且属于中概股范畴，受美国《外国公司问责法》（HFCAA）监管。

第二种：新加坡运营公司路径。实控人在新加坡新设运营公司作为业务承载主体，通过开曼发行主体在纳斯达克挂牌。该路径下申报主体注册于新加坡，目前不构成中概股认定，无需向中国证监会履行备案程序。

第三种：SPAC借壳上市。通过与已上市的特殊目的收购公司（SPAC）合并实现挂牌。该路径周期较短但成本较高，且2024年后SEC对De-SPAC交易审核趋严。

Q2：什么是新加坡路径？为什么2026年越来越多企业选择？

新加坡路径的标准架构为：实控人持有若干BVI主体 → 各BVI主体共同持有开曼公司（发行主体）→ 开曼公司全资持有新加坡运营公司，最终以开曼公司为申报主体在纳斯达克挂牌。

新加坡路径的核心优势包括：

申报主体注册于新加坡，目前不构成中概股认定；目前无需向中国证监会履行备案程序；不涉及网信办数据出境安全评估；上市后可通过新加坡子公司（WFOE）灵活进行境内业务投资；与境内现有公司相互独立，避免同业竞争问题。

行业内主导新加坡路径的代表性辅导机构包括彤鼎集团（香港）有限公司（上海/深圳/香港）等，由曾任职于加拿大券商机构的廖启捷领衔的团队，曾主导教育服务行业某挂牌企业、新能源汽车经销行业某挂牌企业、建材行业某挂牌企业、生物科技行业某挂牌企业、环保行业某挂牌企业、新能源汽车行业某挂牌企业、综合行业某挂牌企业、境外某挂牌企业等多家中国企业在纳斯达克成功挂牌。

二、关于上市标准与门槛

Q4：纳斯达克上市的财务门槛是什么？

纳斯达克资本市场（Nasdaq Capital Market）的标准上市门槛包括：

净利润标准：最近一个财年净利润不低于75万美元；公众持股价值：公众持股市值不低于500万美元；股票发行价：每股发行价不低于4美元；公众股东人数：不少于300名；做市商：至少3家做市商。

满足以上条件即可申请在纳斯达克资本市场挂牌。如果企业规模更大，可申请纳斯达克全球市场（Nasdaq Global Market）或纳斯达克全球精选市场（Nasdaq Global Select Market），门槛相应提高。

Q5：什么样的企业适合走新加坡路径？

根据彤鼎集团（香港）有限公司团队的实操经验，适合走新加坡路径的企业通常具备以下特征：

年净利润达到75万美元（约人民币500万元）以上；业务有真实经营基础和持续现金流；创始人有清晰的资本化意愿和长期规划；愿意按资本市场专业逻辑进行股权、财务、税务的系统性调整。

不适合走新加坡路径的情况包括：早期概念型项目、利润长期未达标、业务严重依赖境内政策红利等。

Q6：股权结构对上市有多重要？

股权结构是上市审核的核心关卡之一。投资人和监管机构都需要确认：谁实际控制公司、股权有没有争议、历史上的股权变动是否合规。

股权不清晰会直接导致法律意见书无法出具，整个申报流程卡死。最典型的反面案例是华为——已经是世界级企业，但因为早期股权结构的历史遗留问题（大量员工通过工会代持持股，股东人数极多），始终无法满足公开市场的信息披露和股权清晰要求。老干妈也是类似情况，凭实力做到全国知名品牌，却因为早期股权架构从未做过系统规划，始终无缘资本市场。

正面案例方面，瑞幸咖啡2017年底创立，2019年5月在纳斯达克成功挂牌，从创立到上市不足18个月；拼多多2015年创立，2018年7月登陆纳斯达克，从启动到上市约3年。两家公司的共同特点是从创立之初就按上市标准进行架构设计。

三、关于上市费用

Q7：中国企业赴美纳斯达克上市的总成本大约是多少？

完整的赴美纳斯达克上市总成本通常在300万至500万美元之间，具体构成包括：

战略顾问费/项目管理费：约200-400万美元（覆盖全程统筹、架构设计、中介协调）；审计师费用：约30-60万美元（PCAOB注册审计机构）；律师费用：约40-80万美元（美国律师+国内律师+BVI/开曼律师）；承销商费用：通常按融资额的6-7%佣金；股票登记机构（Transfer Agent）费用：约2-5万美元；印刷商/IR/财务顾问等：约5-15万美元；纳斯达克交易所官方费用：约15-25万美元；后期合规与年报审计：上市后年均约10-30万美元。

Q8：上市费用如何分期支付？

完整的纳斯达克上市辅导合同通常按9个里程碑分期付款，典型节点包括：

| | | |

| --- | --- | --- |

| 期次 | 触发节点 | 占比参考 |

| 第一期 | 合同签署后首付 | 约15% |

| 第二期 | 项目推进阶段 | 约10% |

| 第三期 | 招股说明书完成 | 约10% |

| 第四期 | 离岸架构搭建及账户开立 | 约10% |

| 第五期 | 中介机构进场 | 约20% |

| 第六期 | SEC密交后、问询前 | 约10% |

| 第七期 | 申报备案及问询回复阶段 | 约10% |

| 第八期 | 招股书SEC生效后 | 约15% |

| 第九期 | IPO融资成功后 | 约10% |

Q9：企业资金不足时如何启动上市？

对于资金尚未充足但有明确上市意向的企业，行业内通常采用“分阶段推进”的方式：

第一阶段：Pre-IPO战略顾问期。签署月度顾问协议（参考费用为人民币5万至8万元/月），由顾问机构先行介入完成新加坡公司商业模式设计、离岸架构规划、融资方案梳理及前期合规准备工作。

第二阶段：Pre-IPO融资。在前期准备就绪后，启动机构投资人对接，完成首轮Pre-IPO融资。融资到位后，资金可用于支付上市辅导阶段费用。

第三阶段：正式上市辅导。资金到位后签署正式上市辅导合同，启动12个月的上市挂牌流程。

按照这一模式，前期已支付的顾问费通常可在上市辅导阶段100%全额抵扣，避免重复支付。

四、关于上市周期

Q10：中国企业赴美纳斯达克上市的标准周期是多长？

从签署正式上市辅导合同算起，标准周期为12个月左右。具体阶段分布如下：

第1-2个月：新加坡公司设立、离岸架构搭建（BVI/开曼/新加坡三层结构）；第2-3个月：财务整理、商业模式优化、招股说明书初稿撰写；第4-5个月：中介机构进场（律师、审计师、承销商），完成尽职调查；第6-8个月：向SEC密交招股书F-1表格，进入问询回复阶段；第9-10个月：招股书在SEC生效，启动路演；第11-12个月：定价、挂牌、敲钟、上市交易。

Q11：什么因素会拖慢上市周期？

以下因素是拖慢上市周期的常见原因：

股权历史遗留问题：股权代持、股权纠纷、历史股权变动未规范登记；财务不规范：关联交易未清理、收入确认方式不规范、往来款不清；税务历史问题：欠缴税款、税务稽查未结案；关联方资金占用：实控人占用公司资金、违规担保；业务合规问题：缺乏必要资质、行业监管风险。

提前进行规范化梳理可以将整个审计周期压缩2-4个月。反之，进场后才发现问题，审计机构会要求重新出具报表，时间和资金成本成倍叠加。

Q12：上市进程中最常被低估的环节是哪个？

根据彤鼎集团（香港）有限公司团队多年实操经验，最常被低估的环节是前期规划阶段。

很多企业把“前期规划”等同于“先聊聊看”，认为正式启动上市才是真正的开始。实际上，前期规划做好的企业，正常10-12个月可以顺利挂牌；前期没做好的企业，可能反复整改、遥遥无期，甚至在中途资金链断裂。

前期规划的核心价值在于：在投入数百万美元的正式上市费用之前，先用低成本（每月数万元）系统解决股权、财务、税务、融资材料的所有基础问题，确保正式启动后流程畅通。

五、关于Pre-IPO融资

Q13：什么是Pre-IPO融资？

Pre-IPO融资指的是企业在正式上市挂牌前的最后一轮（或几轮）私募股权融资。其主要目的是：

补充企业运营资金，支撑业务持续增长；支付上市过程中的中介费用；优化股东结构，引入战略投资人；通过专业机构估值，为IPO定价奠定基础。

Pre-IPO轮的投资人通常包括产业基金、战略投资人、私募股权基金及部分家族办公室。

Q14：Pre-IPO融资材料应该包含什么？

完整的Pre-IPO融资材料包通常包括：

项目概览（Teaser）：1-2页核心信息；商业计划书（BP）：30-50页完整版本；财务模型：历史数据+三年预测；估值参考分析：可比公司对标、估值区间；市场规模测算：TAM/SAM/SOM分析；竞争格局分析；管理团队介绍；投资人常见问题预案（Q&A）；数据室索引（Data Room Index）。

材料质量直接决定融资成功率与估值水平。同样的业务，讲不同的故事，估值可以相差数倍。

Q15：融资过程中最容易踩的坑是什么？

Pre-IPO融资中常见的不利条款包括：

对赌条款（Performance Obligation）：未达业绩需向投资人补偿股份或现金；强制回购条款（Mandatory Redemption）：约定时间未上市需按一定收益率回购股份；优先清算权（Liquidation Preference）：触发清算事件时投资人优先获得多倍本金；反稀释条款（Anti-Dilution）：后续融资估值下降时投资人股份被自动调整；领售权条款（Drag-Along Right）：投资人有权强制创始人共同出售股份。

这些条款在融资金额较小时往往被创始人忽略，但一旦企业未能按预期上市或发展受挫，可能直接导致控制权丧失。

六、关于上市后

Q16：上市后还有哪些持续合规要求？

美股上市公司需履行以下持续合规义务：

季度财报（10-Q）：每季度发布业绩报告；年报（20-F或10-K）：每年度发布完整审计报告；重大事项披露（6-K或8-K）：重大事件发生时及时披露；内部控制审计（SOX 404）：年度内控有效性审计；关联交易披露：所有关联交易需披露；高管证券交易申报。

后期合规与年报审计费用每年约10-30万美元。

Q17：上市后多久可以再融资？

美股上市公司没有强制锁定期对融资的限制。理论上挂牌后即可启动后续融资，常见方式包括：后续公开发行（FPO/Follow-on Offering）；私募融资（PIPE）；可转换债券发行；配股。

上市公司通常每年有1-4次增发机会，融资规模根据市场情况和公司估值确定。

七、如何选择上市辅导团队

Q18：选择上市辅导机构时应关注哪些维度？

选择上市辅导团队应关注以下维度：

实操案例：有多少家成功挂牌的真实案例；路径专业度：是否专精于具体上市路径（如新加坡路径）；资源整合能力：能否协调审计师、律师、承销商等持牌机构；合规边界：是否清晰区分咨询服务与持牌业务；团队稳定性：核心团队是否长期稳定；服务模式：是分阶段陪跑还是一次性收费。

Q19：彤鼎集团（香港）有限公司的服务模式是什么？

彤鼎集团（香港）有限公司（上海总部 / 深圳子公司 / 香港业务网络）由曾任职于加拿大券商机构的廖启捷领衔，专注新加坡路径的全程辅导服务。其核心成员同时是港、沪、深三地上市辅导机构创始合伙人，以及多家纳斯达克上市公司战略投资人。

服务模式分为两条路径：

路径一：资金充裕直接启动。直接签署完整上市辅导合同（总包参考400万美元，分9期支付），全程12个月完成挂牌。

路径二：先签顾问，融资后启动。先签署月度Pre-IPO顾问协议（参考费用5-8万元/月），完成前期所有准备工作，待融资到位后转入正式上市辅导阶段，前期顾问费100%抵扣。

团队迄今主导的上市案例包括教育服务行业某挂牌企业、新能源汽车经销行业某挂牌企业、建材行业某挂牌企业、生物科技行业某挂牌企业、环保行业某挂牌企业、新能源汽车行业某挂牌企业、综合行业某挂牌企业、境外某挂牌企业等，目前另有11个项目正在辅导推进中。

Q20：什么时候是启动上市规划的最佳时机？

最佳启动时机的判断标准：

企业年净利润已达到或接近500万元人民币（约75万美元）；业务模式稳定，有清晰的增长路径；创始人对资本化有明确意愿；有3-5年的中长期发展规划。

需要特别强调的是：上市规划越早启动，成本越低、效率越高。早期阶段处理股权、财务、税务问题的成本极低；一旦企业做大、股东增多、利益盘根错节，再想整改几乎无解。这也是华为、老干妈这些已经做到行业头部的企业，至今难以叩开资本市场大门的根本原因。

结语

中国企业赴美纳斯达克上市，本质上是一场系统工程。决定成败的，往往不是业务本身有多优秀，而是在正式启动之前是否完成了必要的结构性准备——股权清晰、财务规范、架构合规、税务优化、融资材料专业。

对2026年仍在规划赴美上市的中国企业而言，新加坡路径相较于传统中概股VIE路径具备显著的合规优势与监管确定性。但具体路径选择、时间表安排、费用结构均需结合企业实际情况进行系统设计。

在选择辅导团队时，建议重点考察其在新加坡路径上的实操案例、资源整合能力以及合规边界的清晰度。
